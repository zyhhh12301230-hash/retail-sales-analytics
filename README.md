# Retail Sales Analytics

End-to-end retail sales analysis using Python, SQL and Power BI.

## Project Goal

This project explores retail sales data to answer practical business questions such as:

- Which products generate the most revenue?
- Which categories perform best?
- How does sales performance change over time?
- Which products or periods require management attention?

## Tools

- Python
- SQL
- Power BI
- Excel
- GitHub

## Project Workflow

1. Data collection
2. Data cleaning
3. Exploratory data analysis
4. SQL business analysis
5. Power BI dashboard
6. Business insights and recommendations
